What this board is. An implied value is this entry's own claim about what a token would be worth if a protocol's record stayed as it is. It does not predict whether or when a token is issued. A protocol on this board records no token in its DefiLlama record — that is not proof it has none.

How it is scored. radar-2: implied = TVL × category multiple × growth × maturity × breadth. The category multiple is the median market-cap/TVL of the tokenized protocols in that category (fewer than 3 peers: the global median). Market cap is circulating value, not fully-diluted value, so the multiples — and the implied values — read as conservative, lower-bound style estimates. The band widens as confidence falls.
